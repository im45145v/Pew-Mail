# Pew Mail

Pew Mail is an AI-powered HTML Email Design, Management and Delivery Studio that allows individuals, student organizations, committees, communities and small businesses to create beautiful, professional HTML emails without knowing HTML, CSS or email development.

## About

Pew Mail enables users to describe what they want in natural language. An AI agent called **PewPew** assists with:
- Understanding the purpose of the email
- Generating email content
- Creating attractive email layouts
- Applying brand guidelines
- Following design rules and reusable design skills
- Editing existing emails through conversational instructions
- Improving email content and presentation
- Preparing emails for testing and delivery

## Development Setup

1. Clone the repository
2. Install Docker and Docker Compose
3. Start development services:
   ```bash
   docker-compose up -d
   ```
4. Follow the detailed development guide in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
